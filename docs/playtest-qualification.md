## Primary shipped gameplay promise and acquisition

This is a compatibility/stabilization mod, not a new progression tree: its `@Mod` entrypoint (`src/main/java/com/bettercontent/bettercompatfixes/BetterContentFixes.java`) registers conditional hooks for offhand placement, farmland and decorative-vegetation trampling, ambient spawns, fluid mixing, backpack/Curios equipment, sleep interruption, and optional upstream integrations. `src/main/java/com/bettercontent/bettercompatfixes/mixin/` contains the version-sensitive upstream repairs. A player should be able to use the *existing* items and mechanics of the installed mods without crashes, broken interactions or damaged saves; optional integrations must not require absent mods. This is the source's implemented behavior, **not** a claim that every hook is verified in build 69 or on a live multiplayer server.

Acquisition references for pack recipe-root checks: this mod registers no general-purpose new item/block crafting catalogue in `BetterContentFixes.java`; verify the *upstream* item/block IDs from the candidate pack, not invented `better_compat_fixes` items. The authored `src/main/resources/data/minecraft/recipes/{oak,spruce,birch,jungle,acacia,dark_oak,mangrove,cherry}_boat.json`, corresponding `_chest_boat.json`, and `bamboo_{raft,chest_raft}.json` override **vanilla** boat/raft recipe roots (inspect each JSON's ingredient/result). `src/main/resources/data/starcatcher/tags/items/baits.json` affects existing Starcatcher bait admission, while `data/better_compat_fixes/tags/{items,blocks}/realistic_hands/...` and block-policy tags affect classification, not acquisition. `data/better_compat_fixes/worldgen/{structure,structure_set}/deep_void_entrance(s).json` registers worldgen, not an obtainable item; `DeepVoidStructures.java` registers its structure type/piece. `data/forge/loot_modifiers/global_loot_modifiers.json` is a loot-modifier list, not a standalone drop promise. The Starcatcher disabled optional fillet recipe is mirrored only in source GameTest configuration (`build.gradle.kts`); do not present that fixture as a shipped obtainable recipe. Read the full-pack recipe and loot data and verify outputs through actual in-game acquisition before asserting progression viability.
